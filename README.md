# MyFlow

大学生が、締め切りの重なる就活・課題の優先順位を一目で把握し、迷わなくなるアプリ

## 背景

既存のTodoアプリでは時間を自分で入力する必要があり、入力ミスによって優先度を見誤ってしまうことがある。また、優先順位がひと目でわからないため、結局は課題提出のギリギリまで手をつけられないことが多い。

## ターゲットユーザー

アルバイトを掛け持ちしながら、大学の課題・ゼミ・就職活動を両立させている大学3〜4年生

## MVP機能

- ①タスクに期限を設定できる
- ②締め切りの近いタスク順に並び替えられる
- ③就活用・学校用で分けて表示できる
- ④タスクの名前を直せる
- ⑤タスクを削除できる
