# スプリント計画（3スプリント・各1週間）

## ユーザーストーリー優先順位

| 優先度 | 機能 |
|---|---|
| 1 | タスクを作成できる（①） |
| 2 | 並び替え処理（共通処理）を作る（④） |
| 3 | 締め切り順に並び替えられる（②） |
| 3 | 就活/学校で分けて表示できる（③） |
| 4 | タスクを編集できる（⑤） |
| 4 | タスクを削除できる（⑥） |

優先順位の考え方：①（作成）がすべての土台となるため最優先。④（並び替え処理）は②が使う共通処理のため②より先に必要。③・⑤・⑥は①さえあれば独立して作れるが、コンセプトの中心となる表示・並び替え機能（③）を編集・削除より先に実装する方針とした。
