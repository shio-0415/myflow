# 技術選定資料

## 使用技術

| 項目 | 使用技術 |
|---|---|
| フロントエンド | HTML, CSS, JavaScript |
| データの保存 | localStorage（ブラウザ内保存） |
| 画面設計 | Figma |
| エディタ | VSCode |
| バージョン管理 | Git / GitHub |
| 公開（デプロイ） | 静的ページとして公開する（想定。Week22の初日に方法を決める） |

## 選定理由

### フロントエンド：HTML, CSS, JavaScript

これまでの学習で、実際に手を動かして作った経験があるため。

### データの保存：localStorage

- 開発期間が3週間（平日15日）で、実装12日・確認作業2日・デプロイ1日で、すでに余裕がない。サーバーとDBの環境構築が入ると、Must5つを完成させる前に日数が足りなくなる。
- MVPは個人利用で、ログインもない。1人のブラウザの中で保存できれば、Must5つの機能（期限の設定、並び替え、分けて表示、完了、削除）は成立する。
- Laravel＋DBも選択肢だったが、環境構築とデプロイの工数が増えるため、今回は見送る。

## 将来の移行方針

ログイン機能（⑬）を足すときは、データの保存先をサーバー（Laravel＋DB）に移すことを検討する。

移行しやすいように、データの読み書きは、1か所の関数（例：取得、作成、更新、削除）にまとめて書く。保存先を変えるときは、その関数だけを差し替える。サーバー版のAPIの仕様は、api-spec.md に書いてある。
