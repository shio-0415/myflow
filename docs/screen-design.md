# 画面設計

機能の番号と名前は requirements.md が元になる。

Figmaでは5画面分のワイヤーフレームを作成済み（ログイン、会員登録、タスク一覧、タスク入力、進捗確認）。このうちMVPで実際に使用するのは「タスク一覧画面」「タスク入力画面」の2画面。

[Figmaで見る](https://www.figma.com/design/y40bJxE9KZVL7SDDwE5Jgd/%E7%84%A1%E9%A1%8C?node-id=0-1&t=yTlzt4KPgZPNEbWP-1)

## 画面遷移（MVP）

| 画面 | 操作 | 結果 | 関係する機能 |
|---|---|---|---|
| タスク一覧 | 右下の「＋」ボタンを押す | タスク入力画面に移動する | ① |
| タスク入力 | 「タスクを作成する」ボタンを押す | タスクを保存して、タスク一覧画面に戻る | ① |
| タスク一覧 | 並び替えボタンを押す | 締め切りの近いタスクが上に並ぶ | ② |
| タスク一覧 | 就活・学校のタブを押す | 選んだ種類のタスクだけが表示される | ③ |
| タスク一覧 | 各タスクの「完了」ボタンを押す | 同じ画面で、そのタスクが完了の表示になる | ④ |
| タスク一覧 | 各タスクの「削除」ボタンを押す | 同じ画面で、そのタスクが一覧から消える | ⑤ |

## 注記

- 「完了」ボタンと「削除」ボタンは、タスク一覧の各タスクの行に置く。
- Figmaのワイヤーフレームには、この2つのボタンが、まだ描かれていない。実装の前に、Figmaにも描き足す。
- タスクの名前を直す操作（⑥）は、Shouldのため、今回の画面遷移には含めない。
